# Marketing originals

The founder's original screenshots and screen recordings, exactly as captured.
They live outside `public/` so they are not deployed with the site.

What the landing page actually loads is in `public/marketing/landing/`: the
crops in `web/` (cut from these originals), the skeleton GIF and its still, and
the Motion Layer clip `7d.mp4`. To make a new crop, start from a file here and
write the result into `public/marketing/landing/web/`.
